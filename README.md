# The Container and the Content

A 15 to 20 minute learning simulation about course design in Canvas. You play an instructor of record who builds and runs a three-credit course. The container (where things live) comes from a small family of shared templates. The content (lectures, readings, assignments, voice) stays yours.

Built with the six-stage process from Prof. Chad Kennedy's Building Learning Simulations workshop at Arizona State University.

## Run it

Open `index.html` in any modern browser. It is one file with no dependencies and works offline. To host it, turn on GitHub Pages for this repository and serve the root folder.

## What it teaches

- Where a course layout creates friction for students, and what that costs the instructor later.
- That a cheap patch fades and a durable fix lasts.
- That an instructor's voice lives in the content, and that a deviation from the shared layout is a trade with a price.

## Tuning

Every tunable number sits in labeled data tables at the top of the script: `CFG`, `ARCH`, `TPL`, `FIT`, `MODES`, `HYG`, `FREE`, `DEV`, and `EVENTS`. The `PARAMS` table at the bottom labels each number as sourced, derived, or a pedagogical estimate.

## Status

A thin, complete skeleton. Template shapes, build-hour costs, friction effects, and event odds are pedagogical estimates and have not been validated. Five-item findability times are simulated, not measured.
